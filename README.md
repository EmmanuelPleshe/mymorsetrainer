# Morse Trainer

Learn Morse code using the Koch method and spaced repetition. Practice hearing characters and keying them in with a keyboard keyer.

## Quick Start

1. **Install** — Run app on device/emulator
2. **Practice** — Hear character, key it with Spacebar (hold for dah, tap for dit)
3. **Advance** — Reach 90% accuracy to unlock next character

## What is the Koch Method?

The Koch method is a proven technique for learning Morse code efficiently. Instead of learning the alphabet in order (A, B, C...), you start with just two characters (K and M) and add one new character only after you can copy them at 90% accuracy.

**Why it works:**
- Starts at real-world speeds from day one
- Builds muscle memory before cognitive load overwhelms
- New characters are added to existing pool — never replace known ones

**How progression works:**
- Start with K and M (Lesson 1)
- Each lesson adds one character in a specific sequence
- Need ≥90% accuracy on ALL unlocked characters to advance
- Accuracy calculated from last 20 attempts

## Settings Reference

| Setting | What It Does |
|---------|--------------|
| Speed (WPM) | How fast individual sounds play (5-40 WPM) |
| Effective Speed | Overall words-per-minute including pauses |
| Farnsworth | Leave at 10 WPM for standard spacing, or lower for longer pauses |
| Extra Word Space | Adds silence between words |

**Farnsworth method:** Listen at fast speed (18-20 WPM) while pauses between letters are longer. This trains your ear at real speeds without pressure to reply that fast.
